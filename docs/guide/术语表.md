# 接口自动化测试平台

围绕「用例即 DSL、执行即报告」的 API 测试平台:测试工程师以 JSON DSL 编排 HTTP 步骤,选择环境变量触发执行,回看步骤级报告。本文件是全项目统一术语表。

## Language

### 资源

**项目(Project)**:
资源与成员的顶层容器,环境、变量、用例、报告都挂在项目下。
_Avoid_: 工作区、空间

**环境(Environment)**:
一次执行所依赖的外部上下文(base_url、默认头、鉴权、环境级变量)。
_Avoid_: 配置、profile

**变量(Variable)**:
带作用域的键值对,分项目级与环境级,步骤内以 `{{name}}` 引用;可标记加密(`is_secret`)。
_Avoid_: 参数、常量

**用例(TestCase)**:
最小可执行单元:元信息(名称/优先级/标签)+ 一份 DSL。
_Avoid_: 接口、脚本、场景

**目录(Folder)**:
组织用例的树形分组,可嵌套;一个用例属于且仅属于一个目录。
_Avoid_: 模块、分组、集合

**未分类**:
没有归属目录的用例的展示位置(虚拟概念,不是可删除的实体)。
_Avoid_: 默认目录、根节点

### 用例结构

**DSL**:
用例的唯一事实来源:一份带 `dsl_version` 的 JSON 文档,声明步骤序列与全局配置。表单、源码视图都只是它的视图。
_Avoid_: 用例体、配置

**步骤(Step)**:
DSL 里的一个可执行单元,当前仅 `http` 类型。
_Avoid_: 请求、动作

**提取(Extract)**:
从响应中取值写入运行时变量的声明。
_Avoid_: 变量提取、出参

**断言(Assert)**:
对响应的期望声明;单步内全部执行、不短路。
_Avoid_: 校验、检查点

**版本(Version)**:
用例每次保存 DSL 产生的不可变快照;报告与版本号一一对应。
_Avoid_: 修订、历史

### 执行与结果

**调试(Debug)**:
对单个步骤的同步执行,立即返回实际请求、响应、断言与提取结果;不走报告。
_Avoid_: 试跑、TEST、单步执行

**执行(Run)**:
对整条用例的异步触发,产生一条报告。
_Avoid_: 运行、任务

**报告(Report)**:
一次执行的完整记录:汇总统计与逐步骤的请求/响应/断言/提取明细。
_Avoid_: 结果、日志

**事件流(Event Stream)**:
报告详情页的实时进度通道:SSE 端点 `GET /runs/{rid}/events`,以 Redis Streams 承载;事件名与载荷由 `app/event_names.py` 唯一定义。
_Avoid_: 推送、WebSocket、消息队列

**快照(Snapshot)**:
事件流的 `run.snapshot` 事件:服务端从数据库读出的当前完整状态(run + 步骤 + 截断标记),在首次连接、断线重连游标失效、或打开已跑一半的执行时发出,是客户端唯一的「重新同步」入口。
_Avoid_: 全量刷新、重放

### 前端

**编排视图**:
用例详情的主工作形态:左侧步骤列表 + 右侧选中步骤详情面板。
_Avoid_: 表单视图、工作台

**源码视图**:
以 JSON 文本直接编辑 DSL 的高级形态;合法即回写,非法阻止切回编排视图。

**脏步骤**:
编辑过但尚未保存的步骤,以名称旁的小圆点标记;「全部保存」后清除。
_Avoid_: 未保存状态、修改标记
